# Product

## Current release

The native iPhone app is read-oriented and production-connected:

- email OTP sign-in;
- latest progress-photo session and full-screen gallery;
- daily HealthKit step count;
- latest body measurements and existing Timeline data;
- Nutrition and History tabs as explicit coming-soon states.

New photos, nutrition, comparison, and trainer PDF reports remain outside the native v1. Existing web and MCP workflows continue to create data.

## Privacy

Progress photos and InBody originals are private. Clients receive authenticated streams or short-lived signed URLs. Persistent records contain managed asset IDs and R2 object keys, never signed URLs.
