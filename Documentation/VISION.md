# Vision

Form is a private record of one person's body over time. It connects daily behavior with periodic outcomes without judgment, streaks, awards, or motivational pressure.

The photo is the primary evidence. Numbers explain it afterward. The interface should feel like a calm personal document rather than a fitness dashboard.

Core rhythm:

- daily: nutrition and activity;
- weekly: weight and measurements;
- monthly: progress photos;
- quarterly: InBody reports;
- on demand: comparison and a revocable trainer report.
