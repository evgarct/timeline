# TRACE brand assets

The SVG files in this directory are the canonical production masters supplied for the TRACE identity.

- `trace_symbol_primary.svg`: brown symbol on warm paper for primary light surfaces.
- `trace_symbol_dark.svg`: white symbol on near-black for dark surfaces.
- `trace_symbol_mono.svg`: single-color symbol for tinted and small-scale contexts.

Native app icons, asset-catalog variants, favicons, and PWA icons are generated by `npm run icons:generate`. Do not edit the generated PNG files independently. Functional interface actions continue to use SF Symbols; the trace symbol is reserved for branded carriers and signature moments.
